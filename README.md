# calhacks-dashboard

**Work in progress.** Cal Hacks 13.0 by the numbers: 651 projects, 90 winners, and $204k+ in prizes, parsed from the hackathon's real public Devpost pages into a small local dashboard.

So far: raw page snapshots + provenance (`data/calhacks13/`), a parser (`calhacksdash/devpost.py`), and the normalized dataset it builds (`data/calhacks13/dataset.json`). The dashboard itself is next.

Everything here comes from snapshots fetched 2026-11-20, documented in `data/calhacks13/MANIFEST.json`. Numbers are what the pages showed on that date.
